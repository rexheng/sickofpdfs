## Binding names
- `packages/core/src/links.ts`: `ELEVENREADER_STUDENT_URL`, `SITE_ORIGIN`, `waitlistUrl()`.
- `apps/site`: public Worker with static assets. `POST /api/waitlist` takes `{ email, turnstileToken }` and answers `{ ok: true }` or `{ ok: false, reason }`. `GET /api/count` answers `{ waitlist: number, users: number | null }`. D1 table `waitlist(email TEXT PRIMARY KEY, created_at INTEGER)`.
- `apps/mobile`: Capacitor Android app. Package id `com.sickofpdfs.reader`; it is permanent once published, so confirm with the owner before the first store upload.
- Sync stays in `packages/core/src/sync` (pure) so the extension, the app and the web library share it. The client engine (CL11) must not use `chrome.*` directly.
- Page order (R108): a reading's order is `pageOrder: number[] | null` (original page index per shown position). It is stored per document with the settings rows or its own table (the builder decides; schema v9 is reserved for sync, so a new table takes v10).
