# sickofpdfs

A Chrome extension that replaces Chrome's PDF viewer with a Google-Drive-style reader built for studying:

- **Mark up and comment seamlessly**: highlight, underline, bold, strikethrough and comments (Ctrl+Alt+M) on any selection, with Google-Docs-style comment threads.
- **@Claude in any thread**: answers grounded in the PDF, with page citations.
- **Automatic learning library**: every learning PDF you read (papers, textbooks, slides) is saved and searchable. Receipts and other non-learning PDFs leave no trace.
- **Notes stay with the document**, across links, moved files and new versions.
- **Your own cloud**: sync, backup, a web library and a claude.ai connector on your free Cloudflare account.

Status: design phase.
